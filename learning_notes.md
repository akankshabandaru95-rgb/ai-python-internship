# Module 01 – Learning Notes: Introduction to AI & Python

## 1. AI, ML & Deep Learning
- **Artificial Intelligence (AI):** machines performing tasks that normally need human intelligence (reasoning, perception, language).
- **Machine Learning (ML):** a subset of AI where systems learn patterns from data instead of explicit rules. Types: supervised, unsupervised, reinforcement.
- **Deep Learning (DL):** a subset of ML using multi-layer neural networks; excels at images, speech and text.
- Relationship: AI ⊃ ML ⊃ Deep Learning.

## 2. Real-World Applications
- Chatbots and virtual assistants
- Recommendations (Netflix, YouTube, Amazon)
- Healthcare: disease detection from scans
- Finance: fraud detection
- Self-driving cars, face recognition, spam filters

## 3. Python Basics
- Install from python.org; check with `python --version`.
- **Variables:** `name = "Asha"`, `age = 20`
- **Loops:** `for i in range(5):` / `while condition:`
- **Functions:** `def add(a, b): return a + b`
- **Lists:** `nums = [1, 2, 3]`; `append()`, indexing, slicing, looping.

## 4. Key Takeaways
- ML models are only as good as their data.
- Python is the top AI language thanks to NumPy, pandas, scikit-learn, TensorFlow, PyTorch.
- Practice small programs daily to build fluency.
